# NexusPanel 4.0

Nexus 4 unifies the lightweight modules around an event-driven core.

Core layers:
1. Event Bus
2. Decision Engine
3. MicroLM / configured AI routing
4. Autonomous Repair Orchestrator
5. Health Monitor
6. Neural Graph visualization
7. Security and protected-data policy

Design goals:
- event-driven instead of constant polling where possible
- bounded memory
- no mandatory GPU/LLM process
- read-only observability endpoints
- protected-data confirmation boundary
- verification after autonomous changes
